# ALNOV Finance

Mobile-friendly household finance dashboard built as a simple Vite app.

## Demo
- Login as Ali or Novia
- Dummy numbers are based on the uploaded ALNOV FINANCE workbook
- Add Transaction updates the demo immediately in the browser

## Next connection
The UI is intentionally separated from the data layer. Replace the demo data in `src/main.js` with Supabase queries after the Supabase project URL/key and table schema are confirmed.

## Deploy
1. Upload this folder to a GitHub repository.
2. Import the repository into Vercel.
3. Build command: `npm run build`
4. Output directory: `dist`
